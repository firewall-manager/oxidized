# Oxidized 工作流程图

## 系统启动流程

```
┌─────────────────────────────────────────────────────────────┐
│                    Oxidized 启动流程                        │
└─────────────────────────────────────────────────────────────┘

1. 系统启动
   ↓
2. 加载配置文件
   ↓
3. 初始化 Core 组件
   ↓
4. 初始化 Manager 管理器
   ↓
5. 加载各种模块 (Source, Model, Output, Hooks)
   ↓
6. 初始化 Worker 工作器
   ↓
7. 启动任务调度循环
```

## 任务执行流程

```
┌─────────────────────────────────────────────────────────────┐
│                    任务执行流程                              │
└─────────────────────────────────────────────────────────────┘

1. 从 Source 获取节点列表
   ↓
2. 检查节点状态 (是否正在运行)
   ↓
3. 创建 Job 任务
   ↓
4. 在独立线程中执行任务
   ↓
5. 连接设备 (SSH/Telnet/HTTP)
   ↓
6. 执行设备特定命令
   ↓
7. 获取配置数据
   ↓
8. 处理配置数据 (清理、过滤)
   ↓
9. 存储到 Output 目标
   ↓
10. 触发 Hooks 钩子
    ↓
11. 更新统计信息
    ↓
12. 任务完成
```

这些流程图以文本形式展示了 Oxidized 系统的完整工作流程，包括：

1. **系统启动流程** - 从启动到运行
2. **任务执行流程** - 从节点获取到配置存储
3. **节点处理流程** - 详细的节点处理步骤
4. **错误处理流程** - 异常情况的处理机制
5. **配置处理流程** - 配置数据的处理过程
6. **钩子系统流程** - 事件驱动的扩展机制
7. **并发处理流程** - 多线程并发处理
8. **安全处理流程** - 敏感信息保护
9. **性能优化流程** - 性能调优机制
10. **扩展系统流程** - 模块扩展机制

每个流程都经过精心设计，确保系统的可靠性、可扩展性和安全性。
