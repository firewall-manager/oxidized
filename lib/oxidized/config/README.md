# 配置模块

这个目录包含了 Oxidized 配置系统的子模块。

## 文件说明

### `vars.rb`
配置变量模块，提供访问不同级别用户变量的便捷方法。

#### 功能
- 提供 `vars(name)` 方法用于获取变量值
- 支持多级配置优先级：节点级别 > 组模型级别 > 组级别 > 模型级别 > 全局级别
- 自动处理变量插值和类型转换

#### 使用示例
```ruby
# 在节点配置中访问变量
node.vars('enable_password')
node.vars('snmp_community')
```

#### 配置优先级
1. **节点级别** - 直接在节点配置中定义的变量（最高优先级）
2. **组模型级别** - 特定组中特定模型的变量
3. **组级别** - 组级别的变量
4. **模型级别** - 模型级别的变量
5. **全局级别** - 全局配置的变量（最低优先级）

#### 变量类型支持
- 字符串变量
- 布尔值变量（true/false）
- nil值处理
- 自动类型转换

## 配置系统架构

Oxidized 的配置系统采用分层架构：

```
全局配置
├── 组配置
│   ├── 模型配置
│   └── 组模型配置
└── 节点配置
```

这种设计允许在不同级别定义配置，提供了极大的灵活性。
